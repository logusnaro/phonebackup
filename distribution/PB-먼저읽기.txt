PB 2.0 팀원 배포본

[PC]
1. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다.
2. PhoneBackup.exe를 실행합니다.
3. Smart Switch에서 백업을 완료합니다.
4. PB의 '백업 자동 찾기'를 눌러 파일을 분류합니다.
5. 못 찾을 때만 '폴더 직접 추가'에서 상위 폴더를 선택합니다.

[모바일]
1. Release APK를 설치하고 저장소 권한을 허용합니다.
2. '백업 준비 시작' 후 Smart Switch 백업을 진행합니다.
3. 완료 화면을 직접 확인한 뒤 PB의 체크리스트를 완료합니다.
4. 통화녹음 90일 초과 파일 또는 직접 선택한 일반 파일을 정리합니다.

중요:
- PC와 모바일은 서로 연결하거나 비교하지 않습니다.
- Google Drive는 설치 파일 전달용이며 백업 저장소가 아닙니다.
- PB는 Smart Switch PC 원본을 수정하거나 삭제하지 않습니다.
- 백업 완료를 확인하기 전에는 모바일 파일을 삭제할 수 없습니다.
