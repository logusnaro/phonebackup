# PB 2.0 알려진 이슈와 안전 전제

## 의도적으로 하지 않는 기능

- PC와 모바일의 Wi‑Fi/USB 연결, 페어링, 업로드, 원격삭제
- Windows 방화벽 예외와 로컬 HTTPS 서버
- 연락처 가져오기·동기화
- Smart Switch 버튼 자동 조작
- Smart Switch 삼성 전용 컨테이너 해제
- PC의 Smart Switch 원본 파일 개별 삭제

## Android 저장소 제한

- Android 10 이상에서는 제조사 전용 폴더와 문서 폴더를 사용자가 한 번 선택해야 할 수 있습니다.
- Android 11 이상에서 사진·영상·오디오 삭제 시 시스템 승인창이 표시됩니다.
- 일부 파일 관리자가 쓰기 권한을 주지 않으면 목록은 보여도 삭제는 실패할 수 있습니다.
- 수정일이 없는 통화녹음은 안전을 위해 90일 삭제 후보에서 제외합니다.
- 앱을 강제 종료하면 주간 알림이 다음 실행 또는 재부팅 전까지 지연될 수 있습니다.

## Smart Switch 검증 한계

Smart Switch PC 백업 완료 여부를 Android 앱이 확인하는 공개 API가 없습니다. PC와 모바일을 비교하지 않기로 했으므로 모바일의 ‘백업 완료 확인’은 사용자 체크리스트입니다. PB는 이를 실제 백업의 암호학적 증명으로 표현하지 않습니다.

PC의 SHA‑256 무결성 확인은 “현재 등록한 PC 파일을 다시 읽을 수 있고 색인 당시 크기·수정일과 일치한다”는 뜻입니다. 휴대폰 원본과 동일함을 증명하지는 않습니다.

## 안전 규칙

- 백업 전에 삭제 잠금을 풀 수 없습니다.
- 삭제 허용은 24시간 후 만료됩니다.
- 스냅샷에 없거나 이후 변경된 파일은 삭제할 수 없습니다.
- 통화녹음은 수정일 기준 90일을 넘은 파일만 삭제할 수 있습니다.
- 모든 삭제는 사용자가 파일을 선택하고 마지막 경고를 승인해야 합니다.
- Smart Switch 백업 폴더는 PB에서 읽기 전용으로 취급합니다.
- 기존 v1.x DB와 저장 파일은 자동 삭제하지 않습니다.

정식 업무 사용 전에는 각 휴대폰에서 폴더 표시, 이미지 미리보기, 시스템 삭제 승인, 주간 알림을 한 차례씩 확인하세요.
