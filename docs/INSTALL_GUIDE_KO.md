# 업무폰 통합 백업 설치·시험 가이드

이 문서는 현재 빌드된 시험 버전을 두 대의 삼성 Android 업무폰에 설치해 안전하게 확인하기 위한 절차입니다.

## 1. 현재 버전의 범위

현재 버전에서 실제로 시험할 수 있는 기능은 다음입니다.

- Windows PC에서 멤버 추가 및 6자리 연결 코드 생성
- Android 폰에서 PC 연결
- 폰에서 사용자가 선택한 폴더의 파일을 PC로 수동 백업
- 파일 크기·SHA-256 검증·원본 파일명 보존
- 개인 프로필별 PC 연락처 메모(휴대폰 주소록과 동기화하지 않음)
- PC에서 개인 프로필별 연락처 메모 추가·수정·삭제·CSV 내보내기
- 녹음 파일명 기반 날짜·전화번호 메타데이터 추출
- Samsung Smart Switch PC 백업에서 통화녹음·일반 파일을 PB 저장소로 가져오기
- Smart Switch 완료 결과 검증 후에만 90일 삭제 후보 생성
- Android 주 1회 백업·삭제 검토 알림

다음 기능은 현재 화면 또는 데이터 구조만 준비되어 있으며, 실기기 시험 전까지 업무 데이터에 사용하지 마세요.

- 예약 시각에 자동으로 백업을 깨우는 기능
- 휴대폰 파일 삭제 추천 승인과 실제 삭제 명령
- PC에서 휴대폰으로 파일 복구
- 휴대폰 주소록 동기화(의도적으로 제외)
- QR/JSON 복사·붙여넣기 방식(6자리 코드로 대체됨)
- 음성 전사·요약·중요도 분석

따라서 첫 시험은 반드시 테스트 파일과 테스트 연락처로 진행합니다.

### Smart Switch 백업을 PB에 등록하기

Smart Switch에서 백업을 완료한 뒤 PC 앱 상단의 **Smart Switch 가져오기**를 누릅니다. `멤버·기기` 탭에서 대상 멤버를 먼저 선택하고, `문서\Samsung\SmartSwitch\backup\SM-G930S\...` 아래의 백업 회차 폴더를 지정합니다. PB는 원본을 수정하지 않고 SHA-256 검증 후 자체 저장소에 복사하며, 통화녹음은 `통화 녹음` 탭에서 파일명·날짜·상대방 메타데이터로 표시합니다.

Smart Switch의 연락처·문자 데이터는 삼성 전용 컨테이너(`Contact.bk`, `Message.smem`)라 PB가 임의로 풀어 쓰지 않습니다. 이 데이터는 Smart Switch에서 복원하거나 내보내고, 사진·동영상·문서가 Smart Switch 결과에 0건이면 원본 폰 또는 별도 파일 복사로 추가 등록해야 합니다.

PB는 휴대폰 원본을 백업하기 전에 삭제하지 않습니다. 90일 삭제 후보는 Smart Switch 백업 결과가 성공으로 검증되고 PB에 등록된 통화녹음에 한해서만 생성됩니다. 후보를 만들어도 모바일에서 사용자가 승인하고, 원본 경로와 SHA-256이 다시 일치할 때만 삭제합니다.

## 2. 준비

- PC와 두 폰을 같은 Wi‑Fi에 연결합니다.
- Wi‑Fi가 기기 간 통신을 차단하는 게스트망/AP isolation이면 연결할 수 없습니다.
- PC 저장공간에 테스트용 백업 폴더를 만듭니다.
- 각 폰에 테스트용 통화녹음 파일 1~2개와 이미지·문서 파일을 준비합니다.
- 회사 보안 정책상 사내용 APK 설치와 연락처·파일 권한 사용이 승인됐는지 확인합니다.

## 3. Windows 앱 설치

1. [PhoneBackup-windows-x64-portable.zip](../artifacts/PhoneBackup-windows-x64-portable.zip)을 PC에 내려받아 `문서` 등 쓰기 가능한 폴더에 압축을 풉니다.
2. 압축을 푼 폴더의 `PhoneBackup.exe`를 실행합니다. 현재 Windows 배포본은 MSI 설치 프로그램이 아니라 self-contained 폴더형입니다.
3. 이전에 전달된 단일 파일 `PhoneBackup-windows-x64.exe`는 사용하지 말고, 반드시 이 portable ZIP 안의 실행파일을 사용합니다.
4. Windows 방화벽 창이 나타나면 **Private networks(사설 네트워크)**만 허용합니다. Public networks는 허용하지 않습니다.
5. 앱 하단에 `수신 대기: https://<PC주소>:42817`가 표시되는지 확인합니다.
6. `멤버·기기` 탭에서 멤버를 한 명 추가합니다. 예: `내 업무폰`.

Windows SmartScreen이 표시되면 파일 출처가 본인이 만든 사내 빌드인지 확인한 뒤 `추가 정보 → 실행`을 선택합니다. 정식 배포 전에는 release 인증서와 사내 배포 정책을 적용해야 합니다. 앱이 LocalAppData에 쓰지 못하는 PC에서는 실행 폴더 안의 `PhoneBackupData`를 사용합니다.

## 4. Android APK 설치

1. [PhoneBackupAndroid-debug.apk](../artifacts/PhoneBackupAndroid-debug.apk)를 폰으로 전달합니다. 이 빌드는 Android 6.0(API 23) 이상을 지원하므로 Galaxy S7 SM-G930S에서 설치할 수 있습니다.
2. Android가 요청하면 해당 파일을 여는 파일 관리자 또는 브라우저에 `알 수 없는 앱 설치` 권한을 일시적으로 허용합니다.
3. 설치 후에는 해당 설치 권한을 다시 끄는 것을 권장합니다.
4. 앱을 열고 `연결 코드 6자리` 입력란을 준비합니다.

USB로 ADB 설치하는 경우에는 `출처를 알 수 없는 앱` 메뉴가 필요하지 않습니다. 개발자 옵션에서 `USB 디버깅`을 켜고 PC 연결 승인 창에서 이 컴퓨터를 허용하면 PC가 APK를 직접 설치할 수 있습니다. 이 방식으로 SM-G930S(Android 8.0) 설치를 확인했습니다.

QR이나 JSON 복사는 사용하지 않습니다. PC와 폰을 같은 Wi‑Fi에 연결한 뒤 PC가 보여주는 6자리 코드를 Android 앱에 입력하면 PC를 자동으로 찾습니다.

## 5. 첫 연결

1. PC의 `멤버·기기` 탭에서 연결할 멤버를 선택합니다.
2. `기기 연결`을 클릭합니다.
3. PC 창에 표시된 6자리 코드를 확인합니다.
4. 폰 앱에 코드를 입력하고 `PC 찾기`를 누릅니다.
5. `PC 연결 완료`가 표시되는지 확인합니다.
6. 연결이 완료되면 PC DB에 기기가 등록됩니다. 같은 티켓은 10분 후 만료됩니다.

연결 실패 시 먼저 PC와 폰이 같은 Wi‑Fi인지, PC의 42817 포트가 사설 네트워크에서 허용됐는지 확인합니다. 회사 Wi‑Fi가 폰 간 통신을 차단하면 다른 사내 허용망을 사용해야 합니다.

## 6. 폴더 선택과 첫 백업

1. 폰 앱에서 `백업 폴더 선택`을 누릅니다.
2. 시험용 녹음·사진·문서가 포함된 폴더를 선택합니다.
3. 일반 파일이 PB 보조 백업 대상일 때만 폴더 권한을 허용합니다.
4. 정식 백업은 PC에서 Smart Switch를 열고 실행합니다.
5. PC의 `파일·녹음` 탭에서 `검색`을 눌러 파일이 표시되는지 확인합니다.
6. PC 저장 폴더 아래에 멤버/기기별 파일과 `objects` 해시 저장소가 생성되는지 확인합니다.

첫 시험에서는 원본 폴더의 파일을 삭제하지 않습니다. 백업된 파일을 직접 열어 재생·열람하고, 원본과 파일 크기가 같은지 확인합니다.

## 7. PC 연락처 메모

1. PC `PC 연락처 메모` 탭에서 개인 프로필을 선택합니다.
2. 필요한 메모용 연락처만 PC에 직접 추가하거나 수정합니다.
3. 이 목록은 휴대폰 주소록과 동기화하지 않습니다.

## 8. 두 번째 폰 연결

첫 번째 폰 시험이 끝난 뒤에만 두 번째 폰을 연결합니다.

1. PC에서 새 멤버를 추가합니다. 예: `팀원 업무폰`.
2. 해당 멤버를 선택하고 새 연결 티켓을 생성합니다.
3. 두 번째 폰에 APK를 설치하고 동일한 절차로 연결합니다.
4. 폰별 백업 폴더와 파일이 서로 섞이지 않는지 확인합니다.

## 9. 실패 시 복구

- 연결이 안 되면 폰 앱의 저장된 연결 정보를 지우고 PC에서 새 티켓을 발급합니다.
- 잘못 선택한 폴더는 폰 앱의 저장공간 설정에서 다시 선택합니다.
- 백업 중 오류가 발생하면 원본 폰 파일을 건드리지 말고 오류 메시지와 PC의 마지막 백업 시각을 기록합니다.
- 실제 업무 연락처를 수정하기 전 Google·삼성 주소록에서 VCF 내보내기를 별도로 해 둡니다.
- 시험 중에는 휴대폰 파일을 삭제하지 않습니다. 현재 PC가 유일한 사본일 수 있습니다.

## 10. 현재 사용하지 않는 기능

설정 탭의 예약 기능은 Smart Switch 백업 알림 시각을 저장합니다. Smart Switch 백업 버튼 자동 클릭은 제조사 공식 API가 없어 수동 확인이 필요할 수 있습니다. Android는 주 1회 알림을 표시하지만, 삭제는 백업 검증과 사용자 승인 없이는 실행하지 않습니다.

정식 업무 사용 전에는 실제 삼성 모델·Android 버전·통화녹음 파일명 샘플을 받아 파일명 파서와 폴더 권한을 별도로 검증해야 합니다.
