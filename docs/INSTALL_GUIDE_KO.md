# PB 2.0 설치·사용 가이드

## 1. 먼저 알아둘 점

PB 2.0의 PC 앱과 모바일 앱은 서로 연결되지 않습니다. 같은 Wi‑Fi, 방화벽 예외, 6자리 코드, USB 디버깅이 필요 없습니다. 연락처도 동기화하지 않습니다.

정식 백업은 Samsung Smart Switch로 진행합니다. PB는 백업 파일 관리와 휴대폰 정리를 돕습니다.

## 2. Windows 앱

1. `PhoneBackup-windows-x64-portable.zip`을 쓰기 가능한 폴더에 완전히 압축 해제합니다.
2. `PhoneBackup.exe`를 실행합니다.
3. 상단의 **Smart Switch 열기**를 눌러 휴대폰 백업을 완료합니다.
4. PB로 돌아와 **백업 자동 찾기**를 누릅니다.
5. 찾지 못하면 **폴더 직접 추가**에서 Smart Switch 백업 폴더 또는 그 상위 폴더를 선택합니다.
6. 홈의 파일 수와 용량을 확인하고 유형별 탭에서 파일을 관리합니다.
7. 중요한 백업은 **백업 폴더 → 선택 폴더 무결성 확인**으로 SHA‑256 검사를 실행합니다.

### 파일 관리

- 통화녹음: 날짜별 또는 상대방별로 묶고 파일명·전화번호·소속을 검색합니다.
- 사진: 항목을 선택하면 오른쪽에 미리보기가 표시됩니다.
- 모든 탭: 더블클릭하면 파일을 열고, **폴더에서 보기**는 탐색기에서 해당 파일을 선택합니다.
- 삼성 전용 파일(`.spbm`, `.bk`, DB 등): 목록과 크기만 표시하며 내용은 Smart Switch에서 복원합니다.
- **목록에서 제거**: PB의 색인만 지우며 원본 폴더는 그대로 둡니다.

Smart Switch 백업 폴더 안의 파일을 개별 삭제하면 전체 복원이 실패할 수 있습니다. PB는 PC 원본 삭제 버튼을 제공하지 않습니다.

## 3. Android 앱

1. `PhoneBackupAndroid-release-v2.0.0.apk`를 설치합니다.
2. 요청되는 사진·동영상·오디오 권한을 허용합니다.
3. 문서나 제조사 전용 통화녹음 폴더가 안 보이면 **검토 폴더 추가**로 해당 폴더를 선택합니다.
4. 현황에서 저장공간 사용률과 파일 개수를 확인합니다.
5. 위험 알림 기준은 80%, 85%, 90% 중 선택합니다.

### 안전한 삭제 순서

1. 현황에서 **백업 준비 시작**을 누릅니다. PB가 현재 파일 목록의 익명 해시를 고정합니다.
2. USB로 PC에 연결하고 Smart Switch 백업을 시작합니다.
3. Smart Switch에 백업 완료가 표시되고 실패/건너뜀 경고가 없는지 확인합니다.
4. PB로 돌아와 **백업 완료 확인**의 세 항목을 직접 체크합니다.
5. 24시간 동안 스냅샷에 있던 파일만 삭제할 수 있습니다.
6. 통화녹음 탭에서는 90일이 지난 파일만 후보가 됩니다.
7. 일반 파일은 사진 미리보기와 경로를 보고 직접 다중 선택합니다.
8. 마지막 경고와 Android 시스템 승인 후 삭제합니다.

PB는 Smart Switch 결과를 자동으로 확인하지 못합니다. 백업을 실제로 하지 않고 확인 항목만 누르면 PC 사본이 없는 상태에서 파일을 잃을 수 있습니다.

## 4. 주간 운영

- 앱은 주 1회 백업과 정리 검토 알림을 표시합니다.
- 저장공간이 설정 기준을 넘으면 Smart Switch 백업 후 정리합니다.
- 백업 준비 이후 새로 생기거나 내용·크기·수정일이 달라진 파일은 삭제할 수 없습니다.
- 수정일을 확인할 수 없는 통화녹음은 90일 삭제 후보에서 제외됩니다.

## 5. 앱 업데이트

v1.x Debug/Release와 v2.0 Release의 서명이 다르면 덮어쓰기가 안 될 수 있습니다.

1. 기존 PB 앱을 제거합니다.
2. v2.0 APK를 설치합니다.
3. 저장소 권한과 검토 폴더를 다시 지정합니다.

Android 앱 제거 시 앱 내부의 스냅샷과 설정은 지워지지만 Smart Switch PC 백업에는 영향이 없습니다.

## 6. 오류 제출

- PC: **설정·도움말 → 오류 리포트 내보내기**
- 모바일: 상단 **도움말 → 오류 리포트 저장**
- 생성된 `PB-error-report-날짜시간.zip`을 Codex 대화에 첨부하고 **PB 오류 분석**이라고 남깁니다.

리포트에는 앱/OS 버전, 기종, 단계, 파일 개수와 오류 종류만 포함합니다. 인증 정보, 연락처, 파일 내용, 원본 파일명과 절대 경로는 포함하지 않습니다.
